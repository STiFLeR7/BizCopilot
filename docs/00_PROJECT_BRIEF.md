# 00_PROJECT_BRIEF: BizCopilot

## 🎯 Executive Summary
BizCopilot is an autonomous business analytics platform designed to bridge the gap between complex raw data and actionable business insights. It allows non-technical users to query their datasets using natural language, receiving back accurate data retrievals, complex analytical insights, and visual reports.

## 🚀 Vision
To empower every business user with a "Personal Data Analyst" that is as reliable as a human expert but operates at the speed of software.

## 💎 Core Value Propositions
- **Accessibility:** Talk to your data in plain English.
- **Accuracy:** Production-grade SQL generation with verification layers.
- **Deep Analysis:** Beyond simple counts—calculating trends, correlations, and KPIs automatically.
- **Cross-Platform:** Insights available in the boardroom (Web) or on the move (Android).

## 🛠️ Problem Statement
Small to mid-sized businesses often lack dedicated data teams, and existing BI tools (PowerBI/Tableau) require significant technical expertise to set up and query. BizCopilot removes the technical barrier to entry.

## 🎯 MVP Goals
1. Successful natural language to SQL conversion for 90%+ of standard business queries (Aggregations, Joins, Time-series).
2. Direct introspection and indexing of existing PostgreSQL database schemas.
3. Interactive chart generation (Bar, Line, Pie) based on data results.
4. Functional Android and Web clients for unified access.
